Healthcare Integration Projects
BridgeLink HL7 / FHIR Healthcare Integration System
Solo build  |  github.com/erisdothard

End-to-end healthcare integration on BridgeLink 4.6.1 (Innovar Healthcare fork of Mirth Connect) across four channels: ORU lab routing, ADT processing, and FHIR R4 Patient/Observation APIs.

  • HL7 v2.5 parsing across MSH, PID, PV1, OBR, OBX, and EVN segments with try-catch error handling; ACK (MSH+MSA) response generation for every inbound message.
  • ORU_Routing: parses PID/OBR/OBX; NPI provider enrichment via mid-flight reference table lookup against OBR-16; conditional routing of critical (HH/LL) vs normal results; multi-destination write to file and two PostgreSQL databases.
  • ADT_Processing: handles A01 (admit), A03 (discharge), A08 (update) events with UPSERT logic for duplicate-admit resilience. Cross-channel data flow: ORU reads patient admission status from ADT-populated table for clinical-context enrichment.
  • FHIR R4 APIs: separate endpoints returning Observation and Patient Bundles with searchset type, LOINC-coded lab results, unit coding via unitsofmeasure.org, interpretation flags via HL7 ObservationInterpretation CodeSystem.
Stack: BridgeLink 4.6.1, Mirth Connect, PostgreSQL 14+, HL7 v2.5, FHIR R4, LOINC, JavaScript transformers.
